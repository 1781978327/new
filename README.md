# Three.js 3D 游戏项目

这是一个基于 Three.js 的 3D 游戏项目，使用 Vite 构建，部署在 Cloudflare Pages。

## 功能特点

- 3D 场景渲染
- 角色控制
- 敌人 AI
- 碰撞检测
- 实时血条显示
- 高德地图集成

## 技术栈

- Three.js
- Vite
- WebSocket
- Cloudflare Workers
- 高德地图 API

## 开发

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建项目
npm run build
```

## 部署

项目部署在 Cloudflare Pages，通过 GitHub 自动部署。
